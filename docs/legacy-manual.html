Legacy Documentation Archive

The repository contains only a fragment of the original multilingual SMS manual. Its former English, Portuguese and Russian landing-page targets are not present, so they are not offered as working documentation here.

Use the maintained manual
The current, source-checked documentation begins at SMS Docs. It covers the supported media formats, devices, networking, installation, settings and current release.

Preserved encoding guide

The one complete legacy guide retained in this repository is pitrz's high-resolution MPEG-2 encoding guide. Treat its encoder instructions as historical; use the current Video Playback page for SMS's actual playback limits.
