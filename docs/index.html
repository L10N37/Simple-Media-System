Simple Media System for PlayStation 2

SMS turns a bone-stock PlayStation 2 into a media player. It plays video (DivX / XviD / MPEG-4, MPEG-1/2, WMV), audio (MP3, AAC, AC3, FLAC, OGG, WMA) and pictures (JPEG), with soft subtitles and M3U playlists — read from just about every storage device the PS2 can reach: CD/DVD, USB, MX4SIO microSD, the internal HDD (APA and exFAT), i.LINK, MMCE (SD2PSX / MemCard PRO2), and SMB network shares. No HDD, no network adapter, no chip required.

ℹ What SMS is (and what this build is)
Simple Media System (SMS) is a free, open-source media player for the PS2, originally written by Eugene Plotnikov (2001–2005) and maintained since by the PS2 homebrew community. Its party trick has always been playing good-resolution video with sound on an unmodified console straight off a burned disc — no hard drive, no network adapter. This documentation covers an enhanced fork that adds first-class MX4SIO microSD playback, exFAT support on the internal HDD, i.LINK and MMCE devices, a fully on-screen network/SMB setup, and a refreshed look — while staying a stock-console media player at heart. The Getting Started guide gets a file playing in minutes; the sections below are the deep reference.

What this build adds on top of SMS

  • MX4SIO microSD playback — video and audio play smoothly from a microSD in an MX4SIO (SIO2) adapter, with its own device icon and an Autostart MX4SIO toggle. This is the headline feature — see MX4SIO.
  • Internal HDD, exFAT and APA — read media from a modern exFAT drive over ATA (BDM) as well as the classic APA/PFS SMS_Media partition. See Internal HDD.
  • i.LINK (IEEE 1394) storage — mount a FireWire drive as a game/media source. See i.LINK.
  • MMCE devices — browse media from an SD2PSX or MemCard PRO2 in the memory-card slot (mmce0: / mmce1:). See MMCE.
  • On-screen network & SMB setup — configure your IP and connect to a Windows / Samba share entirely from the pad, with a real on-screen keyboard — no pre-made config files to hand-edit. See Network Setup.
  • Settings that save anywhere — configuration persists to the memory card or to the device SMS booted from (USB, HDD…), so a memory-card-less setup keeps its settings. See Settings.
  • A refreshed theme — new desktop artwork and device icons, on top of the existing .smi skin engine. See Themes & Skins.

Where did SMS come from, and what is this fork?

Simple Media System was created by Eugene Plotnikov around 2001–2005 as, in his words, "the simplest DivX player able to play good-resolution movies at good frame rate on the unmodded PS2 without any extra equipment." It introduced CDDAFS — a trick for storing data on an audio CD so the PS2's copy protection accepts a burned disc — and a heavily PS2-optimised port of parts of FFmpeg using the console's IPU for colour conversion. The project was later adopted and modernised by the ps2homebrew community, gaining USB, HDD, network (SMB), a GUI browser, a skin engine and many more formats.

This documentation is for a downstream fork focused on storage breadth: it makes MX4SIO microSD playback work, adds exFAT/ATA HDD, i.LINK and MMCE devices, moves network and SMB setup fully on-screen, and refreshes the look. It is a labour of love built on the work of many — see Credits & Sources.
